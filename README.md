# Entera.ai

An AI-powered document intelligence system that uses OCR, semantic search, and Retrieval-Augmented Generation (RAG) to enable natural language querying over organizational data.

## Tech Stack
- Backend: FastAPI (Python)  
- Frontend: React  
- Vector Database: Qdrant  
- Cloud: Microsoft Azure  
- Containerization: Docker and Docker Compose  

## Features
- User sign-up with email verification
- Upload and manage documents for analysis  
- Ask questions in natural language and get accurate answers  
- Search across documents using semantic understanding  
- View relevant document snippets for each query  
- Fast and interactive web interface for querying data
